# Análisis estadístico del trabajo de grado

**Elementos antropomórficos y asociaciones de sabor**
Maria Gabriela Afanador · Colegio de Estudios Superiores de Administración (CESA)

Este repositorio contiene el código con el que se realizaron los análisis estadísticos del trabajo de grado. Los procedimientos, las variables y los criterios utilizados se describen en el apartado 3.4 del documento.

Los datos de los participantes no se publican, por razones de confidencialidad.

## Contenido

- `run_analysis.py`: programa que realiza todos los análisis en una sola ejecución.
- `requirements.txt`: librerías de Python utilizadas y sus versiones.

## Ejecución

```
pip install -r requirements.txt
python run_analysis.py <carpeta_de_datos> <carpeta_de_resultados>
```
